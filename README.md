# أبناء الشمال: صفحة التحميل العامة

هذا المستودع **العام** فيه فقط: صفحة التحميل (`docs/`) وملفات الـ APK المنشورة بالـ Releases. **لا يحتوي أي كود مصدري.**
الكود المصدري بمستودع **خاص** منفصل، وهو اللي بيبني التطبيقات وبينشر الـ Releases هون.

- `docs/index.html`: صفحة التحميل (GitHub Pages من مجلد `docs`).
- `docs/privacy.html`: سياسة الخصوصية.
- `.github/workflows/mirror.yml`: نسخة سريعة من الـ APK على CDN (اختياري، يدوي).

لا ترفع هون أي ملف غير هاي.
