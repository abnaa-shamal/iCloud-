# شجرة 1 (Shajara One)

نظام حجز مقاعد لقرية الشجرة على خطوط إربد وعمّان والزرقاء، بدل قروبات واتساب. مش تطبيق طلب مشوار: الكابتن بينزّل رحلة
بموعد وسعر وأربع مقاعد، والراكب بيحجز مقعد أو أكثر، والكابتن بيقبل أو بيرفض.
تطبيقان أندرويد (راكب وكابتن) من نفس الكود، ولوحة مشرف ويب، وكلها على Firebase (خطة Spark المجانية).

## شو في بالمشروع

| المجلد | الوصف |
|---|---|
| `app/` | تطبيق أندرويد (Kotlin + Jetpack Compose). نكهتان: `rider` و`captain`. ما فيها أي كود مشرف، المشرف لوحة ويب فقط. |
| `admin-web/` | لوحة المشرف (React + Vite). موافقة الكباتن، الحجوزات، الأماكن، تصدير CSV. |
| `admin-tools/` | سكربت منح صلاحية المشرف (`admin: true`) من بيئة موثوقة. |
| `firestore.rules` | قواعد الأمان. هي خط الدفاع الأساسي، والمقاعد والحجوزات ما بتتغير إلا بشكل متزامن. |
| `rules-test/` | اختبارات القواعد على مُحاكي Firestore المحلي (ما بتلمس بيانات حقيقية). |
| `.github/workflows/build.yml` | بناء الـ APK الموقّع، واختبار القواعد، وبناء لوحة المشرف. |

## الحزم (Package names)

| التطبيق | applicationId |
|---|---|
| الراكب | `jo.shajaraone.rider` |
| الكابتن | `jo.shajaraone.captain` |

لازم يكون التطبيقان مسجّلين بهالحزم بالضبط في Firebase (Project settings ثم Your apps). مجلد الكود الداخلي لسا اسمه `com.shajara.rides` وهذا مقصود: هو مجرد مسار ملفات، مش هوية التطبيق.
الراكب والكابتن تطبيقا أندرويد (APK) كل واحد لحاله، والمشرف لوحة ويب فقط.

## تشغيل سريع

- **لوحة المشرف:** `cd admin-web && npm install && npm test && npm run dev` (راجع `ADMIN_SETUP.md` لإعداد Firebase وصلاحية المشرف).
- **اختبار القواعد:** `cd rules-test && npm install && npm test` (بيحتاج Java).
- **الأندرويد:** البناء بيصير على GitHub Actions. الأسرار (مفاتيح Firebase والتوقيع) بتنحط في Settings ثم Secrets، **ما بتنكتب بالكود أبداً**.

## الأسرار المطلوبة بـ GitHub

`SHAJARA_FIREBASE_API_KEY`, `SHAJARA_FIREBASE_SENDER_ID`, `SHAJARA_RIDER_APP_ID`, `SHAJARA_CAPTAIN_APP_ID`,
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`، واختياري `GOOGLE_SERVICES_JSON_DEV` للنسخة التجريبية.
بدون الأسرار بيفشل `build` وهذا متوقع، أما `rules-test` و`admin-web` فبيشتغلوا بدونها.

## مبادئ الأمان

- ما في رقم هاتف ولا إيميل مكتوب بالكود أو بالقواعد. المشرف حساب عليه `admin: true` فقط.
- ما في كود مشرف بتطبيقات الأندرويد أصلاً، والـ CI بيفحص هالشي بكل بناء.
- تصدير CSV بيعطّل أي خلية تبدأ بـ `=` أو `+` أو `-` أو `@` عشان ما يشتغل كصيغة بالإكسل.
- لا تنشر لوحة المشرف قبل ما تمنح الصلاحية وتنشر `firestore.rules`.
