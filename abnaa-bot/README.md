# بوت أبناء الشمال

تطبيق أندرويد (Kotlin + Compose) بمحادثة مع نموذج ذكاء اصطناعي، وبيقرأ نتائج بناء GitHub Actions (قراءة فقط) وبيعرضها بجدول.

- التعليمات والقواعد: `app/src/main/assets/BOT_INSTRUCTIONS.md` (بتنبعت للنموذج بكل محادثة).
- المفاتيح بتنكتب من شاشة الإعدادات وبتنحفظ على الجوال فقط. **لا تكتبها بأي ملف ولا بالمستودع.**
- ما في أي أمر كتابة على GitHub بالكود (لا push ولا دمج ولا حذف)، وبالتالي ما بيقدر يلمس `main`.
- البناء: على جوالك بـ CodeAssist، أو على GitHub من Workflow «Build bot (lab)» (يدوي، والـAPK بينزل كـ Artifact).
